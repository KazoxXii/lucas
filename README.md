# A7 PROD. E-Commerce Website

A premium, fluid e-commerce template for A7 PROD. clothing, featuring a "boiserie" (wood paneling) aesthetic and adventure theme.

## Getting Started

1.  **Images:** Save your product images in the `images/` subfolders (`tshirts`, `shorts`, `joggings`, `hoodies`) matching the filenames used in `js/main.js`.
2.  **Open:** Open `index.html` in your web browser to view the site.

## Features
-   Responsive Design (Mobile & Desktop)
-   CSS-only Wood Texture (Boiserie) Backgrounds
-   Smooth Scrolling & Animations
-   Product Filtering System
-   Premium Dark Theme with Wood Accents
